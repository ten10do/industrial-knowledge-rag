## 7. Failure analysis

All four false rejections are valid `COLUMN_BOUND` proofs with a vertically merged model
cell. The model anchor is physically located at the first row of a four-row span, while each
value is located in one covered descendant row. The V3.51 validator requires:

`model_row_id == value_row_id`

and therefore emits `MODEL_ROW_OWNERSHIP_MISMATCH` for every valid descendant row.

`merged_cell_span=(4, 1)` records only span size. It does not prove which stable row IDs are
covered by that span, nor does the contract define row ordering from which coverage could be
calculated. Accepting any nearby row based only on a span number would reintroduce the same
proximity risk V3.49 rejected.

The missing semantic is explicit scope coverage, for example an auditable model-cell anchor
plus a stable `covered_row_ids` set. This is a contract representation gap, not an Evidence
threshold issue and not evidence that parser should guess ownership.

## 9. Decision

Decision: **PARTIAL**.

The contract remains fail-closed and shows no unsafe generalization, but it is not complete
enough for an upstream proof producer. Implementing a producer against V3.51 would force it
either to falsify row identity for vertically merged cells or to generate proofs that the
validator rejects. Both outcomes violate the provenance boundary.

V3.52 therefore does not authorize parser/chunker unfreeze, proof-producer feasibility,
runtime Evidence integration, independent sealed validation, or production use.

## 10. Next phase recommendation

After an explicit instruction, enter **V3.53 Vertical Merged-Cell Coverage Contract
Reassessment**.

That phase should remain contract-only and determine the minimum safe extension for
vertically merged ownership. It should compare explicit representations such as:

- anchor cell ID plus `covered_row_ids`;
- scope-specific covered cells/rows rather than one global span;
- stable coverage lineage across page and chunk replication;
- conflict rules when merged scopes overlap;
- rejection when coverage is incomplete, inferred only from proximity, or crosses models.

Do not lower the `COLUMN_BOUND` row invariant, infer coverage from adjacency, modify parser,
integrate Evidence runtime, run a sealed gate, rebuild Support, expand Identity, or enter
Generation Evaluation. V3.52 stops here and waits for the next instruction.
