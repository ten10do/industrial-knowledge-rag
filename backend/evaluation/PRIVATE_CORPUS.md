# Private real-world corpus interface

Create `backend/evaluation/benchmark_private/manifest.json` locally, beginning with `fixtures/private_manifest.template.json`. The whole directory is ignored by Git, so vendor PDFs, annotations, and result JSONs remain outside version control.

Every document must include `document_id`, `file`, `source_name`, `source_type`, manufacturer and equipment metadata, version/date fields, and `commit_allowed: false`. `file` is a relative path below `benchmark_private`; never use an absolute path. The V3.1 runner accepts text-based PDFs and sends each one through the application’s `load_pdf` → `split_documents` → Industrial Chunker path. It never uses a benchmark-only loader.

Optional identity fields are `product_family`, `product_series`, and `model_aliases`. Aliases must come from document titles, manifest metadata, or another verified product-identity source. They are data, not query-specific Python rules. Runtime vector metadata keeps aliases as a flat `|`-separated string.

V3.2 calibration uses a separate ignored `annotations/v32_calibration.json`; copy the committed calibration template, create 20–30 queries with at least 12 answerable and 8 OOD cases, and freeze its hash before evaluation. Calibration queries must not duplicate frozen V3.1 query text. Run it without touching V3.1 evaluation:

```powershell
.\venv\Scripts\python.exe -m backend.evaluation.private_calibration --output backend\evaluation\benchmark_private\annotations\v32_calibration_result.json
```

V3.3 optionally loads `annotations/v33_development.json`. Keep 15–25 queries distinct from the frozen V3.1 text and cover exact/series/family/bare/unknown/multi-identity/identifier/global scopes. The runner verifies its corpus hash and reports model-aware metrics without tracking the private development labels.

Perform the parser audit before labels: retain 5–10 chunk IDs per document, then annotate `relevant_chunk_ids` (multiple IDs are permitted), `relevant_document_ids`, expected model/code/section, category, and difficulty. Freeze the labels with `annotation_sha256`, generated by `annotation_hash`, before running retrieval. Keep queries, labels, and files legal to use, and do not copy them into the committed challenge set.

Run:

```powershell
.\venv\Scripts\python.exe -m backend.evaluation.benchmark_runner --dataset private --mode all
```

The private run always executes the frozen BM25, Dense, Hybrid, and Hybrid + Reranker pipelines. It reports parser audit, chunk/page corpus statistics, category metrics, model confusion, comparison coverage, reranker movement, evidence decisions, false-refusal taxonomy, and latency. Until a local manifest is supplied, the runner reports `REAL_CORPUS_GATE_NOT_RUN`.
