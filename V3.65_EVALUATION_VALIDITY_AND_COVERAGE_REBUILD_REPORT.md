## 6–14. Typed Framework

`backend/evaluation/v365_typed_evaluator.py`:

- EvaluationExpectation: expected_decision + required_claims + forbidden_claims + slices
- RequiredClaim: subject/relation/object/scope(+qualifiers)
- ForbiddenClaim: subject/relation/object/scope + reason
- Prediction: decision(ANSWER/ABSTAIN)+ text
- EvaluationResult: decision_correct/claim_precision/recall/scope_correct/relation_correct/identity_correct/unsafe_claim_count/missing_claim_count/forbidden_claim_hits/verdict/reason_codes

### Claim Checking

- Subject 必须出现在 prediction 中(norm substring)
- Object 数值必须 numeric proximity 匹配(±1%)
- Unit token 必须在 prediction 中存在(当前限制:全文匹配可能误匹配其他位置的单位)
- Relation negation pairs 检测(acceleration↔deceleration 等)
- Scope 必须匹配(≥2 words 时)
- Forbidden claim hit 即 INCORRECT

### Decision Checking

- Gold ABSTAIN + pred ANSWER → FALSE_ANSWER
- Gold ANSWER + pred ABSTAIN → FALSE_REFUSAL
- Gold ANSWER + pred ANSWER → claim-level evaluation
- PARTIAL verdict: 有正确 claims 但不完整或含 forbidden hits → 不冒充 fully correct
