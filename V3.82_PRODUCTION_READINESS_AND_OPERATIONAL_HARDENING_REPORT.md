## 9. Configuration

PASS. `backend/runtime_config.py` loads the existing `.env` and rejects invalid enums, booleans, numeric settings, companion requirements, URLs, configured storage paths, production debug, and incompatible reranker K values. `CONFIGURATION_MATRIX.md` classifies required, optional, experimental, secret, frozen-runtime, and compatibility settings.

## 10. Runtime Modes

- `light`: base dependencies and JSON index.
- `full`: full dependencies, Chroma, frozen embedding identity, compatible index.
- Missing full dependencies now fail fast; the service no longer silently changes to light mode.
- Memory backends are single-process. Redis/RQ is the shared deployment mode.

## 11. Feature Flags

Reranker, section expansion, Support Gate, TableContextBundle, and claim-support experimental paths are default OFF. Explicit activation produces a startup warning. Focused regression prevents default experimental-stack startup. Local NLI/open-sufficiency research code is not promoted as an independently enabled production dependency.

## 12. Secret Safety

`.env`, PDFs, indexes, private benchmark data, results, runtime state, model caches, and frontend build artifacts remain ignored. Docker context excludes the same private boundaries. No secret is passed to `VITE_*`. `ADMIN_TOKEN` and provider/AWS/Redis credentials remain runtime-only.

## 13. Privacy

Structured JSON logs use field and event allowlists. Validation errors include locations/types only, never offending values. Error responses exclude traceback, secret, PDF/chunk text, raw input, and local paths. Readiness details use safe names/types and do not emit absolute paths or exact corpus counts.

## 14. Liveness

PASS. `/live` is process-only and HTTP 200 independent of index/provider failure. `/health` remains a backward-compatible dashboard health endpoint and may report degraded governance/version state without becoming the routing liveness gate.

## 15. Readiness

PASS. `/ready` is mode-aware and returns 503 on required index, embedding/full stack, selected Redis, or selected Redis worker failure. Missing optional LLM configuration returns 200 `degraded`. Responses include safe status, runtime mode, checks, degraded flag, version, and request ID.

## 16. Dependency Matrix

Required/optional classification follows actual architecture:

- Current-mode index: required.
- Full embedding stack/model identity: required only in full mode.
- Redis: required only when selected for queue/limiting.
- Worker: required when Redis queue is selected.
- Groq/DeepSeek: optional for retrieval readiness; missing providers are degraded.

## 17. Index Integrity

PASS. Validation is read-only and never rebuilds. It verifies existence, openability, non-empty count, embedding dimension, embedding model identity, manifest version/schema, metadata schema version, index version, and manifest count for full indexes. Light indexes verify JSON shape. Missing legacy manifest is explicit degraded facts-only validation, not silent compatibility acceptance.

## 18. API Error Contract

PASS. Major HTTP, validation, and unhandled errors use `error_code`, safe `message`, backward-compatible safe `detail`, `request_id`, `retryable`, and limited safe validation details. Raw tracebacks and underlying provider/path messages are not returned.

## 19. Request / Trace ID

PASS. Safe caller `X-Request-ID` values are preserved; invalid values are replaced with non-query-derived IDs. IDs appear in response headers, safe error bodies, request/retrieval/Evidence logs, and background-job `trace_id`. Retries preserve their original trace lineage.

## 20. Structured Logging

PASS. Production defaults to JSON. Minimum operational fields include timestamp, level, request ID, endpoint, runtime mode, status, latency, error code, retrieval/Evidence outcome, and reason family where applicable. Raw query/PDF/chunk/gold/secret/path fields are not allowed.

## 21. Metrics

PASS. In-process Prometheus output provides HTTP request/error count and latency, dependency failures, and queue depth/running/failed gauges. Metric label names are allowlisted; request IDs, query, chunk IDs, paths, and secrets are rejected.

## 22. RAG Operational Metrics

PASS. Runtime instrumentation records retrieval latency, Evidence latency, answer/abstain counts, and abstain reason families. It does not alter the underlying retrieval/Evidence calls or results.

## 23. Failure Injection

Focused tests safely simulate missing/corrupt index, vector-store open failure, embedding failure, Redis failure, worker failure, missing/invalid provider, invalid config/path, unsafe input, and upload rejection. No real provider outage is represented as a successful remote call.
