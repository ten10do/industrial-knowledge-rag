# V3.72 Bounded Identity Compatibility Refinement Report

## Status

**BOUNDED_IDENTITY_REFINEMENT_NOT_JUSTIFIED**

Root cause identified: **chunk-level identity metadata is entirely absent** from the Chroma index, not over-strict guard logic.

## Diagnosis

All failing queries show:
```
query_identity:  model='ACS580'  ← correctly extracted from query
cand_identity:   all fields empty ← chunk metadata has no identity info
```

Without candidate identity data, `identity_relation()` always returns UNKNOWN,
which Evidence treats as incompatible → MODEL_MISMATCH / INSUFFICIENT_EVIDENCE.

## Why Guard Refinement Won't Help

The guard logic correctly rejects when it cannot prove compatibility.
Relaxing it would violate safety principles without fixing root cause.

## Recommended Fix Path

**EVIDENCE_CONTRACT_EXTENSION_REQUIRED**: enrich ingestion pipeline to
attach document-level manufacturer/product metadata to each chunk during indexing.

This enables existing identity guard to function as designed without
any relaxation of safety semantics.
