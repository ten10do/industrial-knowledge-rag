## 4. Attribution policy

False-refusal precedence is frozen and deterministic:

1. `PARSER_LIMIT`: the annotated evidence was not production-parser recoverable.
2. `RETRIEVAL_MISSING`: the gold chunk did not reach selected candidates.
3. `IDENTITY_FALSE_REJECTION`: retrieved gold-compatible evidence was rejected by Identity.
4. `ROUTING_OUTSIDE_VERIFICATION`: the claim did not enter V3.42's VERIFICATION scope.
5. `EVIDENCE_RELATION_BINDING_GAP`: Evidence did not bind the attribute relation.
6. `EVIDENCE_VALUE_BINDING_GAP`: Evidence bound the attribute but not its value/action.
7. `EVIDENCE_OTHER_GAP`: any remaining in-scope Evidence refusal.

For false answers, the reassessment distinguishes:

- `INHERITED_FALSE_ANSWER`: V3.41 answered and V3.42 preserved it unchanged;
- `CANDIDATE_UNSAFE_RELAX`: V3.41 abstained but V3.42 incorrectly upgraded it.

Each record carries two responsibility views:

- `candidate_owner`: what the additive V3.42 candidate is authorized to change;
- `architectural_owner`: the pipeline stage that owns the end-to-end decision under V3.29.

This distinction prevents upstream failures from being blamed on sufficiency while still
recognizing that Evidence, rather than Generation or Support, owns answerability decisions.

## 7. Boundary findings

The reassessment produces four findings:

1. **Local sufficiency is no longer the majority FR bottleneck.** It owns 28.57% of residual
   refusals, below the frozen routing threshold.
2. **Most residual FR cannot be repaired inside V3.42.** Retrieval, Identity, and routing own
   five of seven cases and remain frozen in this phase.
3. **The upgrade-only composition hides baseline safety errors.** Eighteen false answers bypass
   the new relation gate because V3.41 already answered.
4. **The responsibility gap is inside the existing Evidence boundary.** V3.29 already assigns
   answerability to Evidence; no Generation, grounding, normalization, or Support authority is
   needed.

Therefore, repeating V3.39-V3.42-style additive relaxation would optimize the smaller error
class while leaving every inherited false answer structurally unreachable.
