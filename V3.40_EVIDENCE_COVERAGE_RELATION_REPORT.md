## 4. Coverage taxonomy

| Relation | Modeled enum | ANSWER rule | Quota (A/R) |
|---|---|---|---|
| DIRECT_PARAMETER | DIRECT | same parameter block: model + parameter terms + asserted value/range on one line | 6/4 |
| SAME_SECTION_REFERENCE | REFERENCED | explicit same-section anchor in the evidence chunk | 7/3 |
| CROSS_SECTION_REFERENCE | REFERENCED | explicit cross-section/manual/page link matching the queried target | 7/3 |
| PRODUCT_FAMILY_INHERITANCE | INHERITED | explicit family-wide quantifier ("all models", "applied to all … sources"); otherwise ABSTAIN | 7/3 |
| MODULE_PARENT_RELATION | DEPENDENT | explicit compatibility/containment statement | 7/3 |
| CONFIGURATION_DEPENDENCY | DEPENDENT | explicit dependency statement ("must be set", "is necessary to") | 6/4 |
| NEGATIVE_SCOPE_CONFLICT | UNSUPPORTED | high-similarity wrong scope — always ABSTAIN | 0/10 |
| VALUE_SCOPE_CONFLICT | UNSUPPORTED | value from a different parameter/model range — always ABSTAIN | 0/10 |

Candidate output per decision: `coverage_relation` (enum), `confidence`, `reason_code`
(e.g. `DIRECT_PARAMETER_SUPPORTED`, `FAMILY_INHERITANCE_UNSUPPORTED`,
`VALUE_SCOPE_CONFLICT`) plus anchors and lexical coverage. No boolean anywhere.

## 5. Implementation

- `backend/retrieval/evidence_sufficiency_v340.py` — `evidence-v340-coverage-candidate`
  (EXPERIMENTAL_CANDIDATE). Wraps the unchanged `analyze_identity_aware_evidence` path and may
  reconsider only a soft VERIFICATION abstention (`_SOFT_REASONS`) when the typed relation is
  safe (DIRECT/INHERITED/REFERENCED/DEPENDENT) with confidence ≥ 0.75.
- Safety mechanics added on top of V3.39:
  1. **Line-level value co-occurrence** — a value assertion needs model/value/proposition-term
     on ONE physical line, so sibling-row numbers inside ratings tables can never license an
     answer (this was V3.39's identity hard-negative FA regression).
  2. **Typed anchor gates** — INHERITED requires a family quantifier, REFERENCED an explicit
     reference marker, DEPENDENT a compatibility/dependency verb; missing anchors produce
     precise refusal reason codes.
  3. **Value-aware coverage floor** — 0.60 when every asserted value is present (values carry
     the proposition), else 0.72.
  4. All V3.39 guards retained: negation, procedure, contradiction windows, adverse scope,
     identity boundary preserved.
- `backend/evaluation/v340_coverage_relation.py` — public taxonomy, dataset validator
  (counts, quotas, conflict-must-abstain), baseline classifier, metrics, per-relation slices,
  acceptance policy.
- Untouched (verified by SHA256 before/after): `identity_reasoning.py`, retrieval, parser,
  NLI judge, `semantic_judge_localnli.py`, `evidence_support.py` (support-v316.1),
  open sufficiency, `evidence_mixed.py`.
