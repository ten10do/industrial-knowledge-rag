## 4. Reassessment method

V3.48 separates four boundaries instead of treating every preserved false answer as one
Evidence defect:

1. retrieval-to-Evidence selection: the owned counterclaim is absent from all selected
   candidates;
2. bounded Evidence representation: the signal is present but a target metadata alias or
   audited attribute phrase is not bound;
3. table-structure boundary: values are present, but flattened rows/cells lose attribute,
   qualifier, section, or reference ownership;
4. inherited upstream refusal: a V3.45 abstention is preserved and is not caused by the
   V3.47 veto layer.

False-answer annotations were frozen before result generation and require exact coverage of
the 17 observed IDs, a registered class, class-derived responsibility, non-empty rationale,
and explicit selected-signal presence. The three unsafe vetoes have a separate exact-coverage
annotation ledger. False refusals are then classified deterministically: new V3.47 veto,
missing gold retrieval, or inherited frozen-Evidence refusal.

The two section failures show that physical line distance is not a valid ownership model for

nearest-value rule would reproduce the same unsafe behavior.
