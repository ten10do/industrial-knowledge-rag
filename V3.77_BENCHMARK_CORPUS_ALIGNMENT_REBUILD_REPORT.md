the runtime accepts it — the 53/2/14 split mixed recall testing with safety testing. A valid
performance baseline requires answerability defined against the actual frozen corpus.

## 9. Prediction-Blind Gold Method

Machine invariant enforced structurally and by test:

```
BENCHMARK_GOLD_INDEPENDENT_OF_PREDICTION = TRUE
```

- Gold was annotated from exactly two inputs: query text + frozen-corpus page scans
  (production loader), plus the corpus identity manifest. The annotation propositions were
  written before any V3.77 prediction existed (the first real run happened after the freeze).
- Proposition rule: SUPPORTED_ANSWER iff the corpus contains passages entailing at least one
  complete direct answer to the question's information need (definition/spec/procedure) anchored
  by quoted evidence; mention-only/incidental occurrences never qualify.
- The builder (`v377_build_aligned_benchmark.py`) reads no prediction artifact; unit tests scan
  its source for forbidden references (predictions/traces/verdict tokens) and enforce that only
  the V1 *query-text generator* is imported for byte-exact reconstruction.
