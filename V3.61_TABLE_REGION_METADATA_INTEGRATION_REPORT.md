## 13. Architecture Design

### TableRegionMetadata Schema

```python
@dataclass(frozen=True)
class TableRegionMetadata:
    document_id: str
    page: int
    section: str
    table_region_id: str
    bbox: tuple[float, float, float, float]
    region_type: str            # BORDERLESS | PARTIALLY_RULED | FULLY_RULED
    text_span_ids: tuple[str, ...]
    row_band_count: int         # optional
    column_band_count: int      # optional
    caption: str                # optional
    source: str                 # pdfplumber | pypdf_layout | ...
    confidence: float
    producer_version: str
    structure_availability: str  # AVAILABLE | PARTIAL | NONE
    eligibility: str             # ELIGIBLE | INELIGIBLE | AMBIGUOUS
```

### TableContextBundle

```python
@dataclass(frozen=True)
class TableContextBundle:
    primary_chunk_id: str
    sibling_chunk_ids: tuple[str, ...]
    table_region_metadata: TableRegionMetadata
    caption_text: str
    nearby_header_text: str
    section_metadata: dict
    token_estimate: int
```

```
STRUCTURE_ELIGIBILITY != ELIGIBLE → CELL_OWNERSHIP_PROOF_FORBIDDEN

SAME_TABLE_REGION != SUPPORTED_RELATION
LAYOUT_BAND != OWNERSHIP_PROOF
```
