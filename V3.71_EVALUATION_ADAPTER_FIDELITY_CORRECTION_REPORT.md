## Root Cause & Fix

Evidence contract dict uses key `"sufficient"` for coverage status and `"covered"` for covered claim keys. The previous adapter used non-existent key `"requirements_covered"` and never populated `covered_claim_keys`.

Fix: `contract.get("sufficient", False)` → `contract_requirements_covered`; `contract.get("covered", [])` → `covered_claim_keys`.
